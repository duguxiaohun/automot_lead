Bicycle Flow bike

  • Scenario: CrossingBicycleFlow
  • Primary signal: dist_to_biker
  • Bbox fallback: bicycle-sized objects
  • Extractor: _pick_bicycle_flow_events()

Cut-In / Merge cut-in

  • HighwayCutIn · StaticCutIn · ParkingCutIn
  • MergerIntoSlowTraffic(V2) · InvadingTurn
  • Primary signal: dist_to_cutin_vehicle
  • Extractor: _pick_cutin_events()

Brake / Accel Primary brake

  • HardBreakRoute · ControlLoss
  • No distance signal used
  • Signals: speed · accel_x · brake pedal
  • Extractor: _pick_brake_accel_events()

Generic Distance-Driven dist

  • All remaining SCENARIO_CONFIG entries
  • Accident/Construction/Parked/Junction/Door/Pedestrian/…
  • Bbox fallback: class-matched (vehicle/pedestrian/bike)
  • Extractor: _pick_distance_events()

RGB Fallback rgb

  • Triggered when metas AND bboxes lack signal
  • Also used for unknown/unconfigured scenarios
  • Method: frame file-size diff peaks
  • Confidence: 0.5 (lowest tier)

Confidence Tiers

  • metas signal → 0.85 – 0.92
  • bboxes fallback → 0.68 – 0.72
  • rgb fallback → 0.50
