## 对提示词和标定的判断

1. **不能把过去的动作延长到当前。** StaticCutIn/Town13_53_0 f5/6先降速并左跨，f7/8跨线已完成后应恢复速度；ParkingExit/Town03_1721 f44–46恢复，f48保持。成功对照203–205同样覆盖“左借道→右归位→恢复”。横向规则已有“自车、首跨、忽略已完成”，本轮不重复堆叠或改写其优先级。
2. **先降后升仍须保留首个有效降速。** StaticCutIn/Town13_1704_1 f90–95仅一次近停后恢复，不能统一加强STOP；VehicleOpensDoorTwoWays/Town12_3790_1 f54不能把过去反弹当RESUME。每模式90道drop_then_recovery诊断题，原正确A/B/C/D为50/51/48/48；这些是重叠诊断切片，不是90个独立人工错误。
3. **连续停稳与短触零必须分开，截止也不能挪动。** StaticCutIn/Town12_1344_0 f61停稳确认晚于截止，仍DECEL；f62确认刚好进入，STOP。Town13_1704_1 f96后立即持续起步，与f93–95的先降速不同。每模式7道停车确认跨截止题，原正确5/5/4/2。不能为修D的STOP错误放宽门槛，否则会破坏A/B/C原成功边界。
4. **等待与释放要同时保护。** CrossJunctionDefectTrafficLight/Town03_002140 f47仍等待，f49为已确认起步；HardBreakRoute/Town12_2032_0 f44等待、f77起步。释放后可以继续跟随仍可见前车，不要求前车消失。
5. **单选和多标签并非同一监督。** 速度与横向可先后发生，binary可同时YES；choice沿用STOP优先，否则首跨优先。不能把binary的伴随降速当choice的另一个正确词。INVALID只拒绝明显错场景，暗图和普通继续行驶都不能自动变INVALID。

[候选实现](prompt_candidate.py)只改变两处：共用速度段突出“最新帧与当前速度、持续等待/短触零、首个有效变化、持续增速/孤立峰值、正常跟随”；KEEP说明把含糊的“Brief braking can occur”收紧为小调整，并明确有效初始减速后恢复属于DECELERATE。没有向模型加入未来秒数、数值门槛、源场景名、未来RGB、专家控制或答案。二元/单选共用改动，题序、目的说明、横向规则、输出格式保持。

## 可执行回放与不回退检查

新增 [replay_prompt_candidate.py](replay_prompt_candidate.py)：从原生产case重建并核对v23原提示词和题序，验证RGB SHA，导出严格因果输入。`prepare`不加载模型；`replay`用本地完整模型、原v23 adapter、fresh prefill生成全部同题结果，独立保存候选合同和逐题文本SHA。不改adapter训练合同、不绕过原配置检查、不覆盖已有输出。推理请求文件不含GT/未来轨迹；结果文件单独保留离线证据用于配对。

[regression_gate.py](regression_gate.py)重新严格解析raw output，拒绝漏题、重复题、换GT/完整证据/题序/RGB、伪造缓存分数、未登记提示词或消息额外注入未来信息。门槛要求：全量同题；原正确case无退步；原正确答案位无退步；格式无退步；存在真实增益且登记异常窗口之外也有增益。列出每条对→错与错→对，以及context/action/时间边界/异常分组。自对照不会被标成提升。通过也只证明给定开发集上的不回退，不能保证所有未知场景。

已生成A/B/C/D各自的原提示词和候选提示词请求，共8份、每一侧2,022题，位于本轮产物的`*_baseline_inputs` / `*_candidate_inputs`。全量自对照均零回退，因没有增益，`candidate_gate_passed=false`，符合预期。没有候选预测，不报告候选准确率。

从仓库根目录运行（以A为例；四包adapter slot见各自bundle_manifest.json）：

```bash
export PYTHONPATH="$PWD/AutoMoT"
python -m qwen3vl_local.sft_new_loop_phase3.replay_prompt_candidate replay \
  --cases AutoMoT/checkpoints/sft_new_loop_phase3_20260928_220255_4rgb_binary_audit_bundle/lora_production \
  --model-dir AutoMoT/checkpoints/Qwen3.5-4B \
  --adapter-dir AutoMoT/checkpoints/sft_new_loop_phase3_pipeline/20260928_220255/train/best_generation \
  --output AutoMoT/checkpoints/phase3_candidate_model_replay/A
python -m qwen3vl_local.sft_new_loop_phase3.regression_gate \
  --left AutoMoT/checkpoints/sft_new_loop_phase3_20260928_220255_4rgb_binary_audit_bundle/lora_production \
  --right AutoMoT/checkpoints/phase3_candidate_model_replay/A \
  --risks AutoMoT/checkpoints/phase3_audit_20261006/risks.json \
  --output AutoMoT/checkpoints/phase3_candidate_model_replay/A_gate.json
```

门槛未通过CLI退出码2。建议同硬件先用`--variant baseline`回放另一个新目录，确认原结果可复现，再与candidate配对，四模式分别检查；不能用本开发集再次挑checkpoint。模型目录和adapter必须是完整权重目录，本次四个审计包只含adapter元数据，没有adapter权重；本机默认完整4B模型也不存在。
