## 修正此前表述与当前状态

1. “09/11是所有历史binary最高分”不准确：09/10长版67.71%略高于09/11的67.57%。09/11只是在最近三轮精简版中总体最高，左右变道也明显优于09/10。
2. “09/11所有指标最好”不成立：09/10减速、停车、NONE更好，09/15 choice总体最高；没有一个版本包揽所有最优指标。
3. “最新不再精简”不成立：当前仍是短system和短规则，只是比最初v7增加了边界说明。
4. 把v7 prompt接到最新标注/划分上，会形成新的训练组合，**不等于原样恢复09/11**，不能沿用67.57%作为该组合的成绩。
5. 2026-09-17：基于本表的取舍，v11 仅恢复 v7 的紧凑提示词与 choice 措辞；动作实现继续为 v8_bounded_window，RGB 修复、路线隔离与 split seed=20260916 继续沿用。v11 数据/adapter 另建合同，必须重建和新训；没有新增逐帧 RGB 审计，也没有 v11 模型成绩。
