# Phase3 v13 四组训练结果审计（2026-09-20）

结论：四包都是同一 v13 主要动作/NONE 合同，最新两图 D 在本轮 test 总分最高（729/1060，68.77%），但四组均未通过减速 P/R 和 NONE precision 门槛，均评测 final，而非通过守卫的 best_generation。任务覆盖扩大，但旧单动作子集表现下降，不能称为超过历史最优。

## 8. 后续判断

1. 当前v13候选中，D适合作为后续实验的参考：本轮总分最高、生成验证较快。但test已参与本次比较，不能把这个选择包装成未经选择偏差的独立最佳结果，也不应忽略未过守卫。
2. 优先定位DECELERATE↔NONE、RESUME↔NONE、STOP↔DECELERATE/RESUME的混淆，并检查合流/出口、对向侵入。先区分原始证据/时间边界、输入可观测性与模型判断，再决定是否改提示词或训练分配。
3. 保留用户要求的主要动作/NONE语义；当前证据不支持仅因旧choice分数高就回退为不允许NONE。需固定训练预算、输入与未暴露路线，分别评单动作子集和完整主要动作任务，核实收益代价。
4. 本次只增加分析报告；未改训练代码、prompt、标定、分割或原始包，没有新训、重新推理或CARLA闭环。
