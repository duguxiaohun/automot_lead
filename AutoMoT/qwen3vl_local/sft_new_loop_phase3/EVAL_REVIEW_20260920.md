## 2. 错误主要来自哪里

| 案例 | 实际逐帧证据 | 归因与处理 |
|---|---|---|
| #91 对向侵入，RESUME→DECEL | 历史降速，当前之后先确认增速，对向车随后通过 | 事件危险性与实际动作混淆；保留标签，提示词区分冲突占道/已清空 |
| #239 无灯路口，RESUME→DECEL | 自车已通过路口，15.613→20.365m/s | 路口目的过度强调减速等待；改成接近、等待、释放三阶段 |
| #859/#588 | 两者均有夜间 STOP 牌；前者驶离并增速，后者持续近停 | 牌子存在不能替代动作阶段；RESUME/STOP 对照 |
| #860 RESUME→STOP | 当前近零，下一帧 0.604m/s，随后连续增速 | 单帧近零不足以确认等待；保留两采样确认规则 |
| #272 DECEL→NONE | 显著减速，中间只有一个近零采样，随后起步 | 短暂近停不等于 STOP，也不等于无动作；保留阈值 |
| #314 DECEL→LEFT | 跨线在输入末帧前完成，未来保持新车道并减速 | 历史动作误延续到未来 |
| #488/#556 LEFT→DECEL | 自车随后左越线，速度降幅未达阈值 | 相邻车流不必导致减速；自车越线与他车运动分开 |
| #439 LEFT→RIGHT | 施工障碍仍在前方，未来先向左借道；同时增速 | `POST_BYPASS_RETURN` 名称不能强制“下一步右回归” |
| #942 NONE→DECEL | 2s 内基本稳定，较大降速到 +2.5s 才出现 | 时间窗混淆；窗外动作不回填 |
| #513 NONE→DECEL | 早期降幅约 1.827，小于当前阈值约 1.833m/s | 很接近数值边界；不依据模型预测微调阈值 |
| #793 LEFT→NONE | 极暗原图几乎无可辨车道/骑行者；meta 显示借道 | 数值标签保留，视觉复核明确不确定；不能声称靠提示词补出不可见证据 |

以上是证据支持的错误类型，不是已经完成的提示词因果消融。
尤其未来 2/3 秒的精细速度边界和他车变化，可能无法从 0.75 秒 RGB 历史唯一确定。
新训练应分别报告低可见度、速度边界、历史已跨线和冲突释放切片，不能只看总准确率。

## 4. 天气与可观测性

- 正常黑夜、雨雾、逆光保留；本轮不新增亮度阈值过滤，不提亮模型输入，不把看不清改成 NONE。
- 初始化突变按已确认的输入区间隔离。进入隧道、遮挡等自然变化不能仅凭亮度跳变认定异常。
- 低可见度下使用连续帧、车灯、可见边界和当前速度；不编造隐藏行人或车辆。
- 人工笔记区分数值真值可复算和 RGB 可独立确认；#793 明确保留视觉不确定性。
