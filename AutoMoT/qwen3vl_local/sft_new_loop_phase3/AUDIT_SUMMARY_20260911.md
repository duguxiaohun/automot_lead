## 4. audit 输出、训练和门槛

audit 严格 445/765，但只取答案行可得 515/765（67.32%）。107 题证据格式不合格，
其中 70 题答案本身正确：严格 audit 比 production 低，主要混入了额外证据输出的负担。
同时 audit 与 production 的答案有 82 题变化，26 题修好、29 题改坏；不能把全部差距都归为格式。
证据文字是模型自述，不是视觉正确性的独立证明。

训练期 generation val 的 step 2000/4000/6000/8000 exact 为
51.82% / 58.59% / 61.46% / 64.58%，teacher-forced loss 为
0.128600 / 0.119249 / 0.109772 / 0.097740。现有记录没有显示末段验证退化；
包内 train_metrics 截取仅到 step 4990，不能凭不完整训练曲线诊断整轮过拟合。

流水线实际选用 **final（step 9216）**，没有通过训练期全部门槛的 best_generation；
step 8000 fallback 的 STOP recall 77.45% 低于 80% 门槛。最终 test 数值门槛虽通过，
同 RS 错事件负例仅 2 题、1 条独立 route，`same_rs_unique_routes=1 < 2`，仍不能标为 production-ready。
当前 invalid 高分主要反映错道路拒绝能力，不能代替同道路错事件的区分能力。

## 5. 合同与解释边界

本轮 4RGB、语言 LoRA、视觉分支未训练；prompt 为
`sft_new_loop_phase3_high_level_action_v6_observed_behavior_forecast`，动作规则为
`current_wait_first_crossing_v7_rgb_guard`。production prompt SHA256：
`5674c0ff2d60dd6f1700456336092292ee328b68d454b58c7e1b0340e338ae2d`。
包内训练源码指纹与审计开始时本地实现吻合；训练 Git 字段为空，打包 commit 不能冒充训练 commit。

模型只看到历史 0.75 秒 RGB 和当前速度，却要预测未来 1.5–3 秒的离散动作。
晚刹车、下一帧释放、阈值附近的小控制脉冲本身存在可观测性困难。
审计要分开：原始数据与标签计算一致性、当前场景前提是否成立、输入是否足以判断、模型是否真正答错。
不能把所有误差归因于模型参数小，也不能为迎合模型答案任意修改 GT。
