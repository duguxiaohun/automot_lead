# geometry_study 全池 CPU 证据入口

本轮保留已验收的四项修复、159 个源码指纹、a/b/c 阈值及预算。新增独立 `geometry_study_cpu_audit.py/.sh`，不修改 `geometry_study` 包，不因报告工具变化使原数据/权重失效。报告绑定执行时的 study 源码及报告工具 SHA。

## 当前本机状态

已启动真实全池原生准备，没有正式父库可直接复用。当前原始数据、collection 和十二 Town 地图可用；使用原生版本缓存与完整候选依赖证明，没有跳过 SHA 或改写旧库回执。第一轮候选枚举 105.49 秒、依赖散列 443.38 秒；缓存还会按原实现再次检查依赖，这不是 GPU 训练耗时。

完整流程仍在执行，**尚无真实全池准入或三轮 1280 配额通过结论**。本机证据与状态位于：

- `checkpoints/geometry_study_pool_20261022/native_prepare.log`、`native_timings.jsonl`：原生准备及阶段耗时，后者在原生进程结束时追加。
- `pipeline_status.json`：CPU 接续状态；原生成功且固定回执产生后，自动运行新工具。若执行期间冻结源码变化则拒绝接续。
- `study_audit.log`、`full_report/`：接续开始后产生的共同池/容量/方向报告。原生失败时不启动后续，不重启、不偷偷重建失败缓存。

本轮只启动 CPU，后续不会自动训练 GPU。当前阶段未完成，不能用验证过的代码或小池结果替代全池结果。

## 新入口输出与含义

`pool_report.json` 同时包含：

1. 原生 study 准入报告：共同过滤后的 train/val/test 十事件覆盖，固定每事件前 16 验证成员及四组纯类可定义性。
2. 独立的训练容量诊断：各事件锚点、独立物理帧、路线组；按实际三轮 1280、world4 投影。即使 holdout 不合格，也可单独看到容量结果；它绝不写 ready，也不覆盖原准入。计划失败明确记录原始容量错误，不减少配额、增加重复或返回部分计划。
3. 固定验证集支持质量：缺失类别、混合占比、只含混合目标的事件、每类物理组计数和最大单组查询占比。报告是支持量描述，不设置新的人为准入阈值，不改变已冻结成员，也不证明统计可靠。

`--directions` 从原生父库的 **train** 候选重放六动作，包括共同过滤时已排除的锚点。报告翻转、近垂直排除、其它无效和不变的出现次数，并单列按事件/原点/类型去重数；同一原点仍可能因不同当前参考落入不同类型。每类最多保存 12 个确定性候选，限制的是证据体积，不是扫描覆盖。输出当前/局部参考、原生跨线证据、实际填补来源、连续 RGB 路径及 SHA，生成本机 HTML 图册。

填补案例的原生证据来自**被选中的填补端点**，不是缺失起点。图册默认标注 `visual_review_complete=false`：生成图册不等于已经逐帧看图验收。未对 val/test 筛选方向案例，不据结果调阈值。不产生新标签或新的实验划分。

## 使用方式

发布后在服务器已有 AutoMoT 应用根执行；同步仍统一为：

```bash
bash ./sync_automot.sh
bash qwen3vl_local/audit_joint/geometry_study_cpu_audit.sh --directions
```

本轮没有 push；服务器尚未收到这些文件时不能直接运行。入口使用项目 venv 或当前 Python、项目 `lead_data`/collection 和已确认 CARLA 地图路径，不要求模型权重，不选择 GPU。原生父库由既有版本缓存发现/验证；不存在才生成。不会按时间戳选择最新库。可用 `--geometry` 显式固定父库，仍走原生验证。

默认共同缓存为 `checkpoints/geometry_study_v1`，报告为 `checkpoints/geometry_study_cpu_audit_1280`；已有报告拒绝覆盖，再次审计使用明确的语义化 `--output`。`--per-event 1024` 仅用于既有控制预算，不应为了通过 1280 检查而偷换实验。退出码 0 表示正式 CPU 条件及 ready 均通过；2 表示完成诊断但条件不通过；其它异常失败不伪称诊断完成。

通过后仍须查看验证支持、人工核验方向边界候选，再进行独立的小规模 GPU 启动/保存重载/评测接线验证；这个 CPU 入口没有执行这些步骤。完整训练预算和 test 门禁沿用已确认实现。六动作离线历史与几何位置历史的信息差异仍存在，不能称完全等信息消融。
