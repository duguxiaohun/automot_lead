## 运行

在 cr02 或 cee 的 AutoMoT 根目录及已激活环境运行：

```bash
bash ./sync_automot.sh && bash qwen3vl_local/audit_joint/phase12_retrain/taskmix.sh all
```

也可先 `taskmix.sh cpu --run-dir checkpoints/phase12_retrain/<新目录>`，成功后以
`taskmix.sh train --run-dir <同一目录>` 开训。只允许 CPU 边界续跑；已尝试训练的目录保留。
默认模型与资源按当前应用根解析，可用既有 `--model-dir/--data-root/--collection-dir` 指定。
`--parent-data` 指定 v2 父库，`--legacy-parent-data` 指定 v1 父库；旧无 SHA 的父库不能冒用。

## 默认文字 KV 复用

本入口默认 `AUTOMOT_TEXT_PREFIX=1`、`AUTOMOT_TEXT_PREFIX_CACHE=1`，训练、验证、测试
都采用 system → 问题 → 图片合同；原默认入口与旧权重协议保留。
训练仍完整反传，不跨优化更新复用 KV。固定权重推理复用纯文本前缀，按当前图片重算视觉部分。
输入布局、缓存容量和部署合同绑定 CPU-ready 与 adapter，正式在线入口能恢复本版提示词并核验 SHA。
部署使用 adapter 中保存的设置；本版默认设置为：

```bash
export AUTOMOT_TEXT_PREFIX=1 AUTOMOT_TEXT_PREFIX_CACHE=1
export AUTOMOT_TEXT_PREFIX_CACHE_ENTRIES=2 AUTOMOT_TEXT_PREFIX_CACHE_MIB=1024 AUTOMOT_TEXT_PREFIX_CACHE_TOKENS=8192
```

同布局无缓存消融须新建配置匹配的运行，不能给已绑定缓存开启的 adapter 直接关闭缓存。
缓存验证沿用现有规范分段、跨图命中和完整前向对照合同。两题能驻留、复用是否更快要由
新 GPU 运行验证；CPU 准入不等于 4B 性能通过。

各任务共用模型参数与完整问题提示，单项历史优势不保证在组合后同时保留；文字前移也是新输入合同。
因此这是已有证据支持的候选组合，尚不能声称超过历史最优，须以本版新训练输出验收。
