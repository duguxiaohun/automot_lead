Predict native upcoming-action intentions. A=DECELERATE; B=STOP; C=RESUME; D=LANE_CHANGE_LEFT; E=LANE_CHANGE_RIGHT; F=KEEP. Each query compresses two native origins, not an executed half-second action. At every origin use its own speed and native future evidence for A/B/C/F; the current event defines the native action domain. Each query has its own prediction origin T = its latest visible image time + its offset. Reset all action rules at T: speed comparisons use ego speed at T, lane direction uses ego heading at T. For future T, that state must be predicted; observed speed and scene premises are not future measurements. From T, the immediate window is 1.5s, the speed window 2s, and the lane-crossing window 3s. Ignore return crossings only after the first crossing within this query window. A return after T can itself be the first crossing when the outward crossing was before T. STOP means an immediate sustained near-stop or continued waiting before a later release. Low speed alone does not establish continued waiting; immediate pull-away can be RESUME when sustained acceleration begins. Judge the first meaningful speed change relative to speed at T: a clear reduction is DECELERATE even if speed recovers; a sustained speed increase is RESUME without requiring a previous stop.
