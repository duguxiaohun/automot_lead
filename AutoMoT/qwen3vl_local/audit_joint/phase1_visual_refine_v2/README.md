## 修复范围

- 独立的 `rs2_same_direction`：只在原 RS2 定义后补同向相邻车道封闭与对向空间约束的区别，保留真实窄路会车、借道约束。不得依据场景名称、题号、标签、旧预测决定是否应用。
- 独立的 `rs4_signal_head`：只在原 RS4 定义后补灯头与路灯/裸支架/装饰物的区别，保留真实但熄灭或失效的信号灯。两个候选分别试验，不叠加。
- 原 system、格式、问题、标签、其它定义保持；不含相应定义的题目文本逐字不变。RS2 候选每模式影响 716/1024 题，RS4 影响 714/1024 题；不能把“只改一句”误当成“只影响一个类别的输出”。
- 字段级标定必须有对应视觉证据、明确旧值及最新帧相关性。派生后逐行核对全库，只允许审定字段及对应 RS one-hot 改动，其余记录逐字节保护。
- 新增与原评测完成回执绑定的历史正确保护；同时比较本次 baseline 和原始已记录 baseline。重新推理自身漂移不能掩盖历史旧正确损失。任何旧正确答案损失或指标下降都保留证据并拒绝自动接受。

本轮真实本地派生在上一版候选库基础上，仅新增第 678 题 R4→R5 修正（STOP 优先权路口）；672,244 条中其余 672,243 条逐字节不变。训练集、划分和采样不变；修正位于 test，只用于版本化标定/开发诊断，不能计为模型提升，也不能直接拿修正后分数与旧分数混比。提示词实验主比较继续使用原冻结标签。

## 远程验收入口（代码发布后使用）

在当前服务器 AutoMoT 根、已激活原训练环境运行。两台机器都使用当前机器资源；缺失原 pipeline/权重/完整评测回执则报错，不能借用另一台的路径或伪造回执。

```bash
bash qwen3vl_local/audit_joint/phase1_visual_refine_v2/run.sh all --candidate rs2_same_direction
```

另一候选为独立命令：

```bash
bash qwen3vl_local/audit_joint/phase1_visual_refine_v2/run.sh all --candidate rs4_signal_head
```

可显式传 `--pipeline-root`、`--model-dir`、`--data-root`，`GPU_IDS` 选择单张物理 GPU。默认 pipeline 是 `checkpoints/sft_new_loop_phase1_pipeline/judgment_release_20261025_2rgb_endpoints_4rgb`。模型与 adapter 必须匹配冻结输入身份。所有所选模式先完成 CPU 图像/提示词/历史参考准入，然后逐模式原权重全 1024 题成对推理，每臂 fresh KV；不重新训练。

默认输出 `checkpoints/phase1_visual_refine_v2_remote/run_<time>_<pid>_<candidate>/`，每模式生成完整审计包。`[paired-v2:...]` 表示进度；`[DONE]` 表示这批检查没有观测到回退，仍不自动替换默认；`[REVIEW_REQUIRED]` 表示推理/打包完成但质量门未通过，最终退出 2。其它异常直接显示堆栈并非零退出。没有报错不等于质量已经通过，应以最终状态为准。
