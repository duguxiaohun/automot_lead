## 3. 服务器只执行这一次接续

任选 cr02 或 cee，使用**当前机器实际存在**的原目录；两机不互通。不要求三组都跑。确认旧任务已停止，再用已有同步脚本更新源码：

```bash
bash ./sync_automot.sh
```

在该机 AutoMoT 根目录、原 Python 环境执行下面整段。输入本机原输出目录后回车。已知三份目录如下，仅供选择，不自动猜“最新”：

- `checkpoints/phase4_teacher_v24_20261018_121758_779650998`：缺完整题库，严格复验并复用旧回放续建。
- `checkpoints/phase4_teacher_v24_20261018_121925_502799670`：有题库/留出/视图，只做准入。
- `checkpoints/phase4_teacher_v24_20261018_130500_102842314`：有题库/留出，补新视图再准入。

```bash
read -r -p '输入当前机器已有的 Phase4 输出目录：' P4_OLD
P4_OUT="checkpoints/phase4_continue_$(date +%Y%m%d_%H%M%S_%N)"
nohup env PYTHON="$(command -v python)" \
  bash qwen3vl_local/audit_joint/phase4_resume.sh \
  --prepared "$P4_OLD" --output "$P4_OUT" \
  --data-root lead_data --model-dir checkpoints/Qwen3.5-4B \
  > "$P4_OUT.launch.log" 2>&1 < /dev/null &
echo "PID=$! 输出目录：$P4_OUT"
```

若本机原数据/模型不在默认位置，改 `--data-root`、`--model-dir` 为本机实际路径。不要填写另一台服务器的目录。入口记录绝对路径及真实机器上下文；AUTOMOT_SERVER标签不决定资产来源。

入口根据明确目录内的元数据选择步骤；存在但损坏的元数据、缺路线、旧合同、视图不配对等一律阻塞，不自动重放，不改SHA。完整题库/视图只准入；缺视图才在新输出建；题库不完整才进入v86严格复用。新入口对原目录加非阻塞目录锁，防止本入口重复启动；锁不协调历史旧入口，因此不要同时运行旧命令。

CPU阶段保留至少20GiB磁盘守护；实际需求仍由刷新预算检查，不能保证现有空间够。不会训练GPU，仍有完整输入复验及编译的CPU/I/O耗时；不承诺几分钟。旧回放将被引用，成功后也不能删除原目录。

看进度：
