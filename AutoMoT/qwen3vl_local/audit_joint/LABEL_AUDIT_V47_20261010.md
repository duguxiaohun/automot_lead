# Phase3/4 v47：切入历史证据、STOP 预测与提示词续审

## 修复及其依据

1. **显式切入身份不能替代历史位置证据。** 原 `cut_in_identity` 用 `历史相交 is not True` 判定此前在走廊外；当历史导航缺失、求交为 `None` 时也会通过。现在只接受明确的 `False`。`is_cut_in` 和 `cut_in_actors_ids` 两条入口均覆盖，历史已在走廊内及未知时均不新建实例；仍允许历史明确在外、当前进入的显式切入。没有解除通用切入的固定本车道/运动证据要求。
2. **STOP 横穿预测要求同一时间同时占用。** 原 `crossing_clear` 用起终点包围盒的并集，可能把先前的纵向占用与后来的横向占用拼成冲突。新 `crossing_interval` 分别求两轴重叠时间并取交集。反例中 x 轴占用至 1.2 s，y 轴从 1.65 s 才开始，旧实现阻挡、新实现不再把它算作相交。保留当前 AABB、2 s 匀速假设、STOP 停车义务、可见性/未知门与实际占用检查；不是证明车辆真实不会相撞。
3. **提示词 v11 明确上下文不等于证据。** 所有活跃分支追加：事件名称和导航目标定义问题背景，不能证明转移条件成立。保留 v10 的条件合取、运动不等于许可、遮挡不等于清空、迟到新限制不反证此前判断。YES/NO 输出、当前状态/后继结构、冻结 `prompts.py` 与历史人工 rubric 均不改。

Phase3 动作语义与提示词本轮没有改动。新的 Phase4 合同为 v47、老师 v15、同预约计划 v27、空严格 registry v22；没有新增独立批准或变更预约划分。旧 v46 源码存于本地产物 `source_v46/`，已有题库不回写。
