## 实际修正

1. `teacher_events.facts` 原先要求“通道清晰度、优先权两项都已知”才回答 hold/restrict。现在任一项明确为 False 即确定存在阻挡；两项均 True 才确定无阻挡；其余保持 UNKNOWN。proceed/enter/release 的合取许可没有放宽。修复覆盖 U-E3、U-E6、R-E2、R-E5 的实际回放。
2. 两处已由原图确认的车辆消失接入原生生产：R-E3 58→59（actor 4745）、U-E6 43→44（actor 138）。Phase3 的普通扫描与候选缓存路径都执行隔离；Phase4 的原生弱老师编译、人工题逐题准入及加载复验都执行隔离。相关路线先核验前后 RGB/meta/bbox 六份 SHA，缺失或漂移停止，未涉及的路线不要求拥有这两条路线的数据。
3. 人工历史标注按**每题证据包络**检查，不因标注带的一部分覆盖异常而要求整段重新批准。受影响的人工题保留原证据和 `source_quarantine`，目标为 UNKNOWN，不能重新签名后改成监督 YES/NO。弱老师题在编译时排除。已经不确定的题仍留 review_queue，不算新撤回的有效监督。
4. 保留 Phase3 当前已确认 STOP：U-E6 的 36–42 帧并不依赖第 44 帧的消失；只隔离实际读到该异常的第 43 帧。横向动作依赖的额外确认帧仍纳入包络。

## 实跑范围与前后差异

本机 tmux、单进程逐帧重算 45 条既有训练路线、5673 帧。单线程数学库、nice 15、低 I/O 优先级、两核亲和、6 GiB 地址空间限制；可用内存和磁盘余量保护沿用本机入口。正常重算耗时 **368.65 秒，峰值 RSS 370824 KiB（约 362 MiB）**，退出 0。开发中的首轮因接线调整主动中断，保留在 `replay/`，不计完整结果；最终目录是 `replay_final/`。

- Phase3 原始动作与轨迹证据在 5673 帧上全部一致；原生候选 1638 → **1637**。
- Phase4 原始问题 10920 → **9844**，含两模式及 UNKNOWN。按路线、帧、实例、边、图数、事件状态、纵向状态精确匹配的 9306 道问题中，44 道 hold/restrict 从 UNKNOWN → YES；没有许可边从 NO/UNKNOWN → YES。
- 其中 22 道 hold 通过原弱监督门，restrict 仍受 `restriction_seed_tautology` 排除。进入 HOLD 后，后续问题集改变；新状态下增加的 538 道问题全部是 NO/UNKNOWN，移除 1614 道旧状态问题。不能把预先找出的 218 个相关帧简单乘二当最终新增监督量。
- 源异常额外排除原生 R-E3 可准入 enter NO、hold YES 各一题/模式。相同 clear/priority 条件的限制修正与源异常隔离分开记账。
- 准入后的局部弱候选从每模式 3585 → **3591**（466 YES / 3125 NO）；这是去重和人工合并之前的数量，最终入库以原生 manifest 为准。

机器证据在 `checkpoints/joint_label_v43_20261010/`：`question_differences.json`、`phase3_difference.json`、`replay_final/receipt.json`、`inventory/summary.json`。`replay_final/summary.json` 的 `no_production_changes` 仅表示重算工作进程本身只读源数据，不表示本轮没有修改生产源码。

## 已生成原生题库

`checkpoints/joint_label_v43_20261010/data2/` 与 `data4/` 已完成原生编译与加载核验，每模式 **train 3490 / val 273 / test 186**。清单盘点覆盖原有人工题的 80 条路线，其中本轮连续回放 45 条训练路线；`production_coverage.complete_causal_production=false` 如实保留，不能当 8614 条全路线生产。弱训练准入 `trainable=true` 也不代表 `complete_coverage=true`，后者仍为 false。

原始局部 JSONL 通过回执与当前源码合同核验后，保留逐帧记录原字节，只换成绑定该次原生 inventory 的 header，再由原生 `inspect_route/accounting` 全量验收并编译。转换来源 SHA 与产物 SHA 均保存在 `native_build_verification.json`；没有把诊断 header 伪装成全量生产完成。

最终3490题由 **443人工＋3047弱监督** 构成，3490对完整配对且无配对排除。首轮原生采样在两模式、world=1/4下题序一致：每事件1024次，总10240次，YES 2642 / NO 7598。它验证采样编排，不是模型训练或正负1∶1。验收见 `dataset_acceptance.json`；最终各分支支持见 `native_branch_support.json`。

每模式原生编译 3191 条弱候选；384 条同输入重复、16 条同输入冲突先排除，最终还执行人工优先等合并。人工 review_queue 中两图 5 道、四图 7 道已有 UNKNOWN 题新增源异常隔离凭据，不计作新损失的有效训练题。RGB4 原人工 val/test 与 v42 本机参考库逐字节一致。

## RGB 与两个任务的对照

实际查看 14 张连续联系表、**176 个不同 RGB 帧**，覆盖十事件与四个修复相关窗口。每帧绑定 RGB SHA；这是已知标签参与选窗的开发审阅，不是 G2 盲标、原分辨率全路线审查或独立批准。新旧轮次存在重叠，不直接累加为不同帧总数。
