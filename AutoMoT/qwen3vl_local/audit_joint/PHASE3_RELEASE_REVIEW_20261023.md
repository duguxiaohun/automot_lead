# Phase3 发布复核：完成验收与精确白名单

本轮复核保留 base 的兼容快照收尾修复，并修复另一处可复现漏洞：single／abc 原先只凭完成摘要和存在的 metrics 文件即可通过外层验收，空 metrics 或缺失实际权重也可能被误报为完成。

新增包外 `phase3_completion.py`，对 single／a／b／c 核验：

- 当前来源、表示合同、数据 SHA、正式准入和三轮计划；
- 三轮 checkpoint receipt 与 state.pt 散列、每轮3200更新及累计实际曝光；
- 最终第三轮政策、完整 test 成员和标签；
- 从保存的 cases 重新计算 metrics，并绑定外层回执中的文件散列。

这是保存产物一致性检查，不重新加载模型或推理。现有原生评测入口仍负责加载最终权重、模型来源核验及实际推理。它不为任意人为伪造的一整套证据提供真实性认证。

base 继续在 `phase3_native_runtime.prepare` 验证后的同源快照中执行真实 verify_training，保留9600更新、38400逐rank呈现、实际曝光、源码和adapter散列检查。train all 成功验收后继续后四组；已有内层完成的任务可用 verify base补收尾，不重训。统一shell补齐禁用core设置；旧版入口测试和运行说明同步到当前版本。

## 验证结果

从精确暂存白名单构造不含 `.git` 的发布副本，相关 **350项不同CPU测试通过**。首批为350通过、1失败，失败项为混在共享测试文件中的Phase4测试，依赖本轮未发布的Phase4模块。按本轮范围只暂存该文件的Phase3／公共测试，原Phase4测试及代码保留本机；最终该文件16项复核通过，包含在350项内，不累加。未修改训练源码来回避失败。

测试覆盖真实兼容验收子进程、五组顺序收尾、独立补验收、损坏证据拒绝、正式三轮合成预算、有限重复与共享容量、原生小池准备、独立六动作和几何有效性、九类分类loss、微型Qwen反向传播/重载、Gloo及expert合同。收尾使用合成完整消费记录与权重测试替身，不代表4B正式训练已经完成。旧108项与此前各批也不相加。

当前三份ready字节未变且仍ready；single 162项、abc 160项绑定源码与正式全池来源及发布副本一致。base复用原a1fd2101兼容快照，其合同与正式ready一致；原13份base证据SHA未变。没有正式重建数据、改动标签或权重，也没有重写旧回执的SHA。

轻量回执为 `phase3_release_verification_20261023.json`；完整测试XML、保留性证明及暂存范围记录仅留本机 `checkpoints/phase3_release_review_20261023`。只发布Phase3必要源码、测试与轻量文档；Phase4、其它工作、数据/RGB/权重/完整日志不纳入此次提交。
