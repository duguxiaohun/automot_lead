# Phase3：保留 sequence 的 7680 更新四图 choice 实验

本入口只训练和验证新模型，不加载或重跑历史 adapter，不重新建库，不通过 SSH 执行远程任务。用户指定本次在 cr02 运行。旧报告只提供固定验证题及对照数字；不是新增旧模型推理。

## 实验为何这样设置

已收报告的旧/新索引 SHA 相同，均为 `925053e34c47f35dfe4987f14a1be3a8abdc206d75bea31964dc4ca9b8fcee99`。先前性能变化不能归因于这两次数据标签被重建：标定、规则和提示词未变，但采样、有效 batch、更新预算、验证成员和生成实现同时发生过变化。旧四图 choice test 为 274/380，新序列版为 219/380；这些是已经收到的历史结果，不是本轮新实验成绩。

本轮先恢复更新预算，不扩大题库或重复制造数据。四卡每卡 B1、累积1，每轮十事件各1024次，总10240次呈现；每轮2560次 optimizer 更新，三轮7680次更新、30720次呈现。学习率1e-5、warmup2000，与历史7680预算对应。sequence v4继续负责训练选样及排序；不改变动作软配额、每题跨轮固定选项顺序、标签规则、RGB窗口或提示词。B1仍是sequence顺序，不等于退回旧随机采样。梯度检查点开启，冻结视觉特征复用关闭。

因此这是先检验更新预算的恢复实验，不能预先保证恢复旧准确率。若完整预算后减速/恢复行驶仍退化，再根据实际曝光和固定val结果决定下一项训练采样调整，不以test挑下一版。把B2/累积2的数据预算直接翻四倍会同时改变曝光量与重复次数，本轮不混入这个变量。

## 固定验证、接续与报告

- loss固定历史同一批160题，generation固定同一批320题，十事件各16/32；缺题、重复、成员/顺序/动作支持改变均拒绝，不自动换题。采用原单题greedy KV解码循环，四rank各自生成、原生汇总，避免rank0单独等待其它rank。
- `quick`只到第1轮/2560更新，原计划仍为3轮/7680，保存optimizer、scheduler、RNG及sequence曝光历史的完整epoch断点。第1轮与历史第3轮的对照会明确标记预算不同；首轮好转并不等于完整恢复。
- `complete --resume .../epoch_0001`接着执行第2、3轮，而非另外再跑三轮。源、题库、本机base资产、world及外部实验适配器绑定不一致会拒绝。只接受本实验的完整epoch1或2，不能用旧B2实验断点接入本预算。
- 新的完整三轮完成后才评测同一批380道test，不重跑旧模型、不自动选最优checkpoint；quick阶段不触碰test推理。
- 输出包含来源SHA、实际hostname/服务器标签/绝对路径、环境版本、动作曝光差异、逐题原始输出、实际事件消费计数和逐动作召回/预测量对照。成功只表示执行完成，质量仍需审阅。至少保留20GiB磁盘空间，首错停止，不自动重试；ZIP上限30MiB，不包含权重/RGB。
- 新入口位于audit_joint，原生Phase3和共享sequence代码字节未改。独立225项发布清单包含运行依赖和规则文件；没有改变Phase4的发布指针或旧断点SHA。

## cr02 先跑一次新四图 choice 首轮

在原automot环境中执行整段。日志和结果都在当前AutoMoT根目录下，不放/tmp；不要删除这个新目录或原题库。若本机原始数据/基座不在以下位置，修改对应参数；缺少输入会报错，不自动重建或下载。

```bash
cd /home/cruser1/lda/AutoMoT
bash ./sync_automot.sh && (
  set -euo pipefail
  ulimit -S -c 0 2>/dev/null || true
  P3_RUN="phase3_sequence_7680_$(date +%Y%m%d_%H%M%S_%N)"
  mkdir -- "$P3_RUN"
  nohup env AUTOMOT_SERVER=cr02 GPU_IDS=0,1,2,3 PYTHON="$(command -v python)" \
    bash qwen3vl_local/audit_joint/phase3_sequence_trial.sh \
    --index checkpoints/phase3_four_data_20261017_223254_120427458/frame_index.jsonl \
    --data-root lead_data --model-dir checkpoints/Qwen3.5-4B \
    --output "$P3_RUN/result" --stage quick \
    > "$P3_RUN/launch.log" 2>&1 < /dev/null &
  P3_PID=$!
  printf 'PID=%s\n输出目录=%s\n' "$P3_PID" "$PWD/$P3_RUN"
)
```
