# v48：U-E1 路线参考系与完成条件拆分

本轮修复上轮已定位的弯道跟车缺陷，范围为 Phase4 原生弱老师及活跃提示词。Phase3 动作规则、历史人工参考标签、split 预约、采样预算均不改。旧实验使用旧源码；新规则与提示词需要新题库和新 run，不给旧 adapter 换合同续训。

## 代码变化

- U-E1 的前车检索、最近前车比较、持续跟车、间距增长与前车替换统一使用因果导航折线的路线切线/弧长间距。此前只有骑行跟车分支投影，普通前车仍在自车轴中判横向速度。不同弯道位置的车身朝向不再直接当作横穿。
- 必须有相同 road/lane 身份与可解析路线投影；自交、重复经过同一位置但路线站位不同、导航终点外、改道后缺原始导航均不能凭推测补齐。缺失 lane 也不再因双方都为 null 被认为相同。
- 原来的五帧距离、闭合、相对速度及波动、单步与累计间距损失门保留，额外障碍、可见性、异常隔离、STOP/优先权仍独立约束。修复不意味着所有投影稳定候选均为 YES。
- `following_stability_evidence()` 与 `progress_stability_evidence()` 是生产判定实际调用的逐项诊断，避免审计另抄一套阈值。缺少完整测量返回 UNKNOWN；问题理由记录未成立项。
- 活跃提示词 v12 明确沿道路判断前车运动；若 complete 同时要求事件解除与稳定行进，须分别满足。冻结 `prompts.py` 不改，也不向学生提供特权速度阈值或演员 ID。

## “完成”定义的边界

| 场景 | 当前合同 | 本轮处理 |
| --- | --- | --- |
| U-E1 普通跟车完成 | 事件约束解除，且处于已建立的稳定跟车/行进状态 | 修复坐标系；原数值门不放宽；保留跟车状态与恢复状态的区别 |
| U-E7 等路口事件完成 | 路口几何结束、当前冲突解除及稳定行进分别判断 | 三帧速度门保持；新增逐项证据，不把越过出口等同稳定行进 |
| 历史人工 YES 与弱门不一致 | 人工所见完成与弱规则代理可能不同 | 保留原参考及疑点，不凭一个必要条件宣布人工错标，不按留出答案调阈值 |

本轮没有“统一改成 YES/NO”。人工口径和弱代理的完全一致性、精细速度门能否从短 RGB 输入观察，仍需独立可观察性审核。Phase3 预测录制动作，Phase4 判断条件，不要求同帧动作与条件答案同义。
