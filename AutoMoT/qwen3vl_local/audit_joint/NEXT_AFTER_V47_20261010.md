## 如何取得新版代码而保留旧实验环境

旧实验仍绑定原源码。不要直接在它的运行目录 `git pull` 后用 v47 加载旧 adapter。需要准备新版时，从原仓库的任意目录执行下面命令，在仓库外创建独立源码工作树；命令只取代码，不复制大数据或启动任务：

```bash
git fetch origin main
AUDIT_REPO_ROOT=$(git rev-parse --show-toplevel)
AUDIT_NEW_WORKTREE="$(dirname "$AUDIT_REPO_ROOT")/automot-v47-review"
git worktree add --detach "$AUDIT_NEW_WORKTREE" origin/main
git -C "$AUDIT_NEW_WORKTREE" rev-parse HEAD
```

核对输出与本次交付提交一致。若目标目录已存在，Git会拒绝覆盖；不要清理旧目录或使用强制选项。工作树可能采用仓库根含 `AutoMoT/` 或扁平应用布局，后续数据路径必须按实际应用根确定；此处不启动建库。
