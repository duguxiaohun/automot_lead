# BEV-only：不加 / 加 action token 训练审计

审计日期：2026-09-22。输入为本地 `checkpoints/training_audit_1`、`training_audit_2`；前者关闭 token，后者开启。这里只审计已交付训练记录，未运行新模型推理。

## 结论

**action token 对特殊事件更有帮助，但自然分布上的整体改善很小，且存在退化组。** 两组均完成7轮；按训练实际选优指标，最优记录均是第7轮 / step 12719。自然分布加权 ADE 从0.496626降到0.492540（改善0.82%）；事件均衡 waypoint ADE 从0.563744m降到0.466161m（改善17.31%）。普通背景、UE4及动作过滤帧出现退化，不能宣称全场景均提升。

这是未来真值 action token 的离线条件实验，不是在线动作预测能力。单 seed、无逐帧误差/配对置信区间、未提供test结果，不能认定统计显著、闭环提升或泛化提升。

## 最优权重与总体指标

本轮 `best_selection_metric=natural_ade`，实际公式为 `0.5×route ADE + 1.0×waypoint ADE`，不是FM loss。完整val在EMA权重下从固定高斯噪声进行10步Euler采样。两组都应选原训练目录的 `best.pt`，并核对step=12719；这里根据记录识别最优步，不声称已验证该权重文件。

按相同loss权重重新计算的事件均衡加权ADE为 **0.608467 → 0.510757（-16.06%）**。记录里的 `event_balanced_trajectory_score` 是 route/waypoint均值（0.326595→0.277677），与训练使用的0.5/1.0加权公式不同；不能混用。事件均衡口径依次按十特殊桶各1份、普通背景2份加权，稀有事件得到更高权重。

FM loss上升0.74%，同时采样waypoint ADE下降0.86%并不矛盾：前者评向量场回归，后者评纯噪声积分结果。route FDE上升2.36%，也说明收益并非所有指标一致。
